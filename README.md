# Caminos del Tigre — Prototipo 6

Landing institucional, responsive y accesible construida con HTML, CSS y JavaScript sin dependencias de ejecución.

## Dirección visual

Composición editorial de gran escala, jerarquía tipográfica marcada y espacios amplios. Combina azul institucional, amarillo de énfasis y una línea tricolor, con fotografía institucional optimizada para web en el hero y las secciones territoriales.

## Mapa de secciones

Barra institucional, encabezado, hero, programa, funcionamiento en siete etapas, público, cobertura, preguntas frecuentes, formulario de registro, contacto y pie institucional.

## Componentes

- Encabezado responsive y navegación por anclas.
- Fotografías institucionales en WebP con dimensiones declaradas, carga diferida fuera del hero y textos alternativos descriptivos.
- Secuencia de siete pasos.
- Perfiles habilitados y cobertura territorial.
- Acordeón accesible.
- Recorrido demostrativo del formulario de registro.
- Pie institucional y mapa del sitio.

## Contenido pendiente

- URL pública de registro y reglas definitivas del formulario.
- Perfiles autorizados para presentar reportes.
- Estados, periodicidad y datos autorizados del mapa.
- Canales oficiales, horario y responsable de contacto.
- Validación jurídica, técnica y UX del formulario.

## Uso local

Abra `index.html` directamente o sirva la carpeta con un servidor estático:

```powershell
python -m http.server 4178 --directory landing-caminos-tigre-v6
```

Luego visite `http://localhost:4178/`.
